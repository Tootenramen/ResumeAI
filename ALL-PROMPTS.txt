VISUAL LANGUAGE (adapt this into a responsive scrolling website: follow the layout on desktop, stack gracefully on mobile)
- Full-bleed dark slate masthead (#2b333e) with the name in 42px light-weight Inter, the title below it in red (#f0483e), then a 3-line summary in 9.5px light grey.
- A darker contact strip (#1f252d) directly under it with small line icons (email, phone).

- Skills shown as five dots (filled dark slate / hollow outline).
- Generous whitespace, nothing decorative beyond the red accent.

ANIMATION & INTERACTION
- Hero: name slides up and fades in, title wipes in from the left in red, summary fades after.
- Each job card reveals on scroll (fade + 16px rise, 80ms stagger). The red section underline draws from left to right when its heading enters view.
- Skill dots fill one by one, left to right, when the Skills block scrolls into view.
- Sticky slim top bar that turns solid slate after you scroll past the hero; the active section's link gets a red underline.
- Scroll-triggered reveals via IntersectionObserver (no heavy libraries; small vanilla JS only, GSAP via CDN only if truly needed).
- Smooth anchor scrolling and a sticky nav with links to each section.
- Animate only transform/opacity where possible so it stays at 60fps.
- Respect prefers-reduced-motion: if set, disable all non-essential motion and show content immediately.
