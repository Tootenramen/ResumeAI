Full Websites — ready to send

29 finished, animated resume websites. Open one, love it, then make it yours in 3 minutes (guide below). Each is a single file: edit the details block, drag it onto app.netlify.com/drop, and you have a free link for hiring managers.

Make it yours in 3 minutes

  1. Get your data block. Paste your current resume into any AI (Claude, ChatGPT) with the prompt below. It returns a ready const DATA = {…}.
  2. Swap it in. Right-click the site file → open with Notepad. Find /* ===== EDIT YOUR DETAILS HERE ===== */ near the top of the script and replace the DATA block with yours. Save.
  3. Check it. Double-click the file to preview. Add ?static to the link to see it without animations.
  4. Publish free. Drag the file onto app.netlify.com/drop (or use GitHub Pages). Copy the link into your applications. Use Download PDF in the site for a print version.
  5. Social preview. Edit the <title> and description/og tags in the file head to your name — link-preview bots don't run JavaScript.
